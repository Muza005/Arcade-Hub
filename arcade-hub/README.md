# Arcade Hub

Платформа аркад для компании у одного экрана: ноутбук или ТВ, до 10 игроков, телефоны вместо геймпадов. В корне репозитория — документы и код платформы, рядом отдельными папками — игры.

## Карта репозитория

```
arcade-hub/
  README.md                 ← этот файл
  CLAUDE.md                 правила для нейросети (подгружаются сами в Claude Code)
  ARCADE_HUB_SPEC.md        спецификация платформы: меню, комната, телефоны, лобби, итоги
  ARCADE_HUB_STAGES.md      этапы платформы А0–А8 и шаблон «Расширения платформы»

  hub/                      код меню, комнаты, лобби, итогов, настроек
  controller/               код страницы телефона (одна на все игры)
  server/                   код сервера комнат
  engine/                   общий движок: цикл, rng с сидом, пулы, ввод
  shared/                   протокол, манифест игры, реестр игр, общие константы, словарь

  dots/                     тестовая игра «Точки» — шаблон новой игры
    DOTS_SPEC.md

  space-war/                игра Space War
    SPACE_WAR_SPEC.md       спецификация игры
    SPACE_WAR_STAGES.md     этапы игры Б0–Б13
    …код игры
```

Папки с кодом появляются по ходу этапов. Сделан этап **А0 — фундамент**: `engine/`, `shared/`, пустая страница хаба с тестовой точкой; `controller/` и `server/` пока пустые.

## Запуск

Нужен Node 22+.

```bash
npm install
npm run dev        # хаб на http://localhost:5173 (стрелки двигают тестовую точку)
```

| Команда | Что делает |
|---|---|
| `npm run dev` / `npm start` | Dev-сервер Vite |
| `npm run build` | TypeScript → ESLint (граница платформы и игры, запрет `Math.random()`) → сборка в `dist/`. Любое нарушение ломает сборку |
| `npm test` | Тесты движка и правил ESLint |
| `npm run lint`, `npm run typecheck` | Проверки по отдельности |

## Какой документ к чему относится

| Файл | Интерфейс | Что внутри |
|---|---|---|
| `ARCADE_HUB_SPEC.md` | Arcade Hub — меню и общая платформа | Всё, что одинаково для любых игр: меню игр, окно игры, комната и QR, профиль, контроллер телефона, пауза, настройки, лобби, итоги, протокол, визуальный язык |
| `ARCADE_HUB_STAGES.md` | Arcade Hub — меню и общая платформа | Этапы А0–А8, «Расширение платформы», как добавить новую игру |
| `dots/DOTS_SPEC.md` | Игра «Точки» | Тестовая игра для проверки платформы и шаблон новых игр |
| `space-war/SPACE_WAR_SPEC.md` | Игра Space War | Только своё: правила, константы, Power, экран саботажника, лобби, графика, итоги, манифест |
| `space-war/SPACE_WAR_STAGES.md` | Игра Space War | Этапы Б0–Б13 |

Правило имён: документ платформы начинается с `ARCADE_HUB_`, документ игры — с имени игры (`SPACE_WAR_`, `DOTS_`, у следующей игры — её имя).

## Порядок разработки

1. Платформа целиком по `ARCADE_HUB_STAGES.md` (А0–А8), проверка на «Точках».
2. Space War по `space-war/SPACE_WAR_STAGES.md` (Б0–Б13).
3. Следующие игры — копией папки `dots/` со своими `<ИГРА>_SPEC.md` и `<ИГРА>_STAGES.md`.

## Где ещё смотреть

- **Макеты меню и телефона** — артефакт «Arcade Hub — макеты меню» (меню игр, окно игры, контроллер, настройки, пауза). Относится к платформе.
- **Подробная документация Space War с обоснованиями решений** — документ «Космическая аркада — документация и поэтапный план». Это история обсуждения и пояснения «почему так»; для реализации главные — файлы `*_SPEC.md`.
