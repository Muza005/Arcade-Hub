# «Точки» — шаблон новой игры

«Точки» проверяют каждый этап платформы и служат образцом для новой игры. Правила — в `DOTS_SPEC.md`.

## Что где лежит

| Файл | Что внутри |
|---|---|
| `manifest.ts` | Манифест игры (ARCADE_HUB_SPEC §16): название, игроки, режимы, `load()` |
| `strings.ts` | Словарь игры, ru и en. Все видимые строки — только отсюда |
| `config.ts` | Все числа игры. В остальном коде чисел нет |
| `sim.ts` | Симуляция без графики. Случайность — только `engine/rng.ts` с сидом матча, поэтому матч воспроизводится по сиду и вводу |
| `game.ts` | Модуль игры по контракту `GameModule`: `init` → `update`/`render` → `end(result)` → `dispose` |
| `sim.test.ts` | Тесты симуляции, в том числе на детерминизм |
| `assets/` | Обложка, картинка карточки, логотип, иконки режимов |

Импортировать можно только `engine/` и `shared/` (и npm-пакеты). Импорт из `hub/`, `controller/`, `server/` и других игр ломает сборку.

## Как сделать новую игру

1. Скопировать папку: `cp -r dots neon-drift`.
2. Переименовать `DOTS_SPEC.md` в `NEON_DRIFT_SPEC.md` и написать спецификацию, начиная с разделов «Место в платформе» и «Манифест». Общее не повторять — ссылаться на `ARCADE_HUB_SPEC.md`. Рядом — `NEON_DRIFT_STAGES.md` по образцу `space-war/SPACE_WAR_STAGES.md`.
3. В `manifest.ts` поменять `id`, `accent` (тёмный текст `#04121A` на нём — контраст не ниже 4.5:1), игроков, режимы, `version`; переименовать экспорт (`neonDriftManifest`).
4. Заполнить `strings.ts`, `config.ts`, заменить картинки в `assets/`.
5. Переписать `sim.ts` и `game.ts` под свою игру, сохранив контракт `GameModule`.
6. Добавить манифест в реестр `shared/games.ts` — это **единственная** правка вне папки игры.
7. Проверить: `npm run build` без ошибок, `npm test` зелёный, «Точки» по-прежнему запускаются и доигрываются.

## Контракт в двух словах

- Платформа сама крутит цикл: `update(dt)` с фиксированным шагом 60 Гц и `render(alpha)` каждый кадр.
- Ввод: `ctx.input.read(playerId)` → `{ x, y, btn }`; откуда он (клавиатура, телефон, бот), игра не знает.
- Рисовать — внутри `ctx.mount`; `engine/stage.ts` даёт Pixi-сцену с миром 1920×1080, вписанным в экран.
- Конец матча — `ctx.end(result)`; после этого платформа вызывает `dispose()`, игра освобождает всё.
- `pause()` / `resume()` — игра сама замораживает симуляцию.
