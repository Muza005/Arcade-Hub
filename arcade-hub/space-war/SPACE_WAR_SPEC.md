# SPACE WAR — спецификация игры

Игра **Space War** для платформы Arcade Hub. Этот документ описывает только саму игру. Всё общее — меню, комната, телефоны, контроллер, лобби, пауза, настройки, итоги — описано в `../ARCADE_HUB_SPEC.md` и здесь не повторяется.

Если в задаче этапа что-то не сказано — смотри сюда, потом в `ARCADE_HUB_SPEC.md`. Если и там не сказано — не придумывай, а спроси.

## 0. Правила работы для исполнителя

Действуют все правила раздела 0 `ARCADE_HUB_SPEC.md`. Для Space War дополнительно:

1. Делай только текущий этап из `SPACE_WAR_STAGES.md`.
2. Весь код, графика, звуки и константы игры — только в папке `space-war/`. Импорт — только из `engine/` и `shared/`.
3. Все числа баланса — только из `space-war/config.ts` (раздел 4).
4. Всё, что включается и выключается (усиления, саботаж, столкновения, стрельба), — флаги в одном файле `space-war/features.ts`.
5. Если нужна возможность, которой нет у платформы, — остановись и предложи этап «Расширение платформы» из `ARCADE_HUB_STAGES.md`. Обходы внутри папки игры запрещены.

## 1. Что такое Space War

2D-аркада-избегалка на одном общем экране. Игроки уворачиваются от астероидов, отстреливаются и рискуют ради множителя очков. До 10 игроков: двое с клавиатуры (WASD и стрелки), остальные с телефонов; недостающих добирают ботами. Матч — 20 волн, около 20 минут.

## 2. Место в платформе

| Берёт у платформы | Добавляет своё |
|---|---|
| Комната, игроки, профиль (ник, цвет) | Форма корпуса игрока (поле лобби) |
| Контроллер: джойстик/стрелки/гироскоп, главная кнопка, пауза, настройки | Главная кнопка = Power; число патронов и ободок накопления на ней |
| Лобби: слоты, боты, режимы, схема настроек | Три режима, настройки матча, поведение ботов трёх уровней |
| Пауза и настройки на телефоне | Строка состояния на паузе («Волна 7 · 0:34»), предупреждение «Корабль в игре — его могут сбить» |
| Оболочка итогов, рекорды, записи, ежедневный сид | Повтор, награды, строки итогов, `meta()`, воспроизведение записи |
| Протокол | Сообщение `g` саботажа и поле `st.game` (раздел 10) |
| Особые раскладки контроллера (через «Расширение платформы») | Экран саботажника (раздел 7) |

## 4. Константы (`space-war/config.ts`)

Все значения — стартовые. Помеченные `TUNE` подбираются игрой: оставь их в конфиге с комментарием. Общие числа (частота шага, число игроков, длина ника, настройки гироскопа, размеры кнопок) — в `shared/config.ts` платформы.

```ts
// Качество и производительность
FRAME_BUDGET_MS = 8                  // наш бюджет из 16 мс
QUALITY_DOWNGRADE_FRAME_MS = 20      // кадр дольше этого...
QUALITY_DOWNGRADE_HOLD_S = 2         // ...2 с подряд → качество на ступень ниже
QUALITY_PROBE_S = 3                  // первичный замер при старте
PARTICLES_MAX = { mid: 300, high: 1500 }
BUNDLE_GAME_KB = 500

// Корабль
SHIP_THRUST, SHIP_DRAG, SHIP_MAX_SPEED = TUNE   // масса и сопротивление, без телепорта
SHIP_HITBOX = circle, одинаковый радиус у всех форм корпуса
SHIP_LIVES = 5
DISCONNECT_INVULN_S = 2
KEYBOARD_MAX = 2

// Обратная связь на телефон
VIBRATE_HIT_MS = 40
// взрыв — длинная вибрация, подбор усиления — два коротких импульса (TUNE)

// Стрельба и патроны
AMMO_MAX = 10
AMMO_BASE_S = 3                      // t = AMMO_BASE_S / (1 + 0.4 * (m - 1)), m — итоговый множитель
AMMO_MULT_K = 0.4
ASTEROID_HP = { small: 1, medium: [4, 5], large: 8 }   // мелкий — с одного выстрела (решение заказчика)

// Множитель
MULT_MAX = 5
MULT_STEPS = [3, 5, 8, 12]           // сближений до ×2, ×3, ×4, ×5 (всего 28)
NEAR_MISS_COOLDOWN_S = 0.5
NEAR_MISS_DISTANCE = TUNE
MULT_IDLE_RESET_S = 5                // см. раздел 14, п. 3

// Очки
SCORE_WAVE = 100                     // × номер волны, без множителя
SCORE_NEAR_MISS = 10                 // × множитель
SCORE_ASTEROID = { small: 20, medium: 50, large: 120 }  // × множитель
SCORE_BOSS = 1000
SCORE_REVIVE = 300                   // только кооператив
SCORE_LIFE_LEFT = 250                // за каждую жизнь в конце

// Волны
WAVE_LIMIT = 20
WAVE_PAUSE_S = 5
WAVE_DURATION_S = min(30 + 3 * (wave - 1), 60)
FLOW_PLAYER_K = 0.5                  // поток = база * (1 + 0.5 * (N - 1))
WAVE_DENSITY_GROWTH, WAVE_SPEED_GROWTH = TUNE
CAMERA_ZOOM_STEP_PLAYERS = 2         // шаг отдаления на каждые 2 игрока

// Боссы
BOSS_HP_PLAYER_K = 0.7               // прочность = база * (1 + 0.7 * (N - 1))
BOSS_BASE_HP = { seeder: 25, giant: 30 }
SWARM_DURATION_S = 25
VORTEX_DURATION_S = 30

// Усиления
POWERUP_DROP_CHANCE = 1 / 20         // с разрушенного астероида
POWERUP_LIFETIME_S = 10
SHIELD_S = 8
FREEZE_S = 3
OVERLOAD_S = 5
OVERLOAD_FACTOR = 2                  // максимум итогового множителя ×10
JAMMER_S = 5
JAMMER_TARGETS = 3                   // всегда 3 ближайших соперника, даже если их меньше

// Саботаж
SAB_COOLDOWN_S = { rock: 5, bomb: 8 }  // + 1 с за каждого погибшего
SAB_ROCK_HP = [4, 5]
SAB_SPEED_STEPS = [0.5, 1, 2, 3]     // × скорость обычного астероида, для камня и бомбы
SAB_STEP_THRESHOLDS = [0.25, 0.5, 0.75]  // доли диагонали рамки
SAB_CANCEL_CM = 1.5                  // короче — отмена; тап тоже отмена
SAB_FRAME_MIN_HEIGHT = 0.6           // рамка ≥ 60% высоты телефона

// Воскрешение и призрак
GHOST_S = 15                         // настраивается в лобби
REVIVE_SHARDS = 3
```

## 5. Игровые правила
### Поле и корабль
- Границы поля жёсткие: корабль упирается в край, без отскока и без перехода на другую сторону.
- Движение через ускорение, массу и сопротивление. Отпустил управление — корабль плавно гасит скорость.
- У всех форм корпуса одинаковый хитбокс-окружность.

### Астероиды
- Спавн и дрейф, раскол на более мелкие. Размеры: мелкий, средний, крупный.
- Три визуальных состояния по урону: целый; повреждённый (трещины, сколы); на последнем попадании (светящиеся разломы).
- **Осколки никогда не наносят урон.**
- Расчищать поле не обязательно: камни пролетают насквозь и уходят за границу.
- Формы процедурные, кэшируются в текстуры.

### Стрельба (кнопка Power)
- Автонаведение на ближайший астероид.
- Патроны личные (даже в кооперативе), копятся по таймеру, максимум 10.
- Множитель ускоряет накопление по формуле из констант. При Перегрузке в формулу идёт итоговый множитель (до ×10).
- По снарядам саботажника стрелять можно: камень разрушается как обычный, бомба от попадания взрывается на месте.

### Множитель за риск
- Есть у каждого игрока в любом режиме.
- Растёт за сближения (пролёт вплотную к астероиду) по ступеням `MULT_STEPS`.
- Ограничители: каждый астероид засчитывается один раз; между засчитанными сближениями пауза 0,5 с.
- **Обнуляется сразу до ×1** (не сползает) в трёх случаях: игрок перестал рисковать (истёк таймер простоя); удар астероидом; столкновение с другим кораблём.
- Таран: множитель теряют **оба** участника. В кооперативе таран не работает. Если столкновения выключены в лобби, корабли проходят насквозь.
- Множитель умножает очки за сближения и разрушение, но не за пережитые волны.

### Показ множителя (только на большом экране, не на телефоне)
- Цифра мелко у ника над кораблём, **только с ×2**. «×1» не показывается никогда; при обнулении цифра просто гаснет.
- Эффект на корабле в цвет игрока, шкала нарастающая (разница ×4→×5 резче, чем ×2→×3):

| Ступень | Эффект |
|---|---|
| ×1 | Ничего |
| ×2 | Корпус чуть ярче |
| ×3 | Корпус заметно ярче, мягкое свечение |
| ×4 | Блестящий след, искры гаснут ~1 с |
| ×5 | Полная яркость, след длиннее, искры гаснут 1,5–2 с |

- Никаких колец и ореолов вокруг корабля. Искры мелкие, аддитивные.
- Эффекты лидеров **никогда не отключаются** из-за их количества. Общий лимит частиц делится между всеми, и следы у всех просто становятся короче.
- На низком качестве искры отключаются, яркость корпуса остаётся.

### Перегрузка — отдельный слой поверх множителя
- Итоговый множитель = накопленный × 2 на 5 секунд.
- Показ: рядом с цифрой отдельный значок «×2» (например «×5 ×2»). Если накопленного множителя нет, горит только «×2».
- Корабль и след на это время **ярко-бордовые** независимо от цвета игрока. Бордовый заметно отличается от красного из палитры. Ник и основная цифра остаются в цвете игрока.
- За 1 с до конца бордовый тускнеет.
- Удар или таран сжигает накопленную ступень, но **не Перегрузку**: «×2» доживает свои 5 с.
- Повторный подбор только сбрасывает таймер на 5 с и не складывается. Так же работают все усиления с таймером.

### Режимы
| Режим | Жизни | Цвета |
|---|---|---|
| Кооператив | Общий пул | Разные |
| Соревнование | У каждого свои | Разные |
| Командное | Пул внутри команды | Одинаковый цвет — одна команда |

- Победитель в соревновании — по очкам.
- Команды собираются по цвету в лобби и могут быть неравными.
- Выбор режима не меняет настройки лобби: значения по умолчанию одинаковы везде.

### Волны
- 20 волн, двадцатая — финал. Между волнами 5 с передышки; номер волны и одна короткая строка о том, что усложнилось, приходят уведомлением на несколько секунд (`engine/notice.ts`, ARCADE_HUB_SPEC §16 «Интерфейс матча») — игра не останавливается и поле ничем не закрыто.
- Осложнения выпадают случайно (через rng), не в каждой волне, и действуют всю волну: затемнение (виден только круг вокруг каждого корабля), ускоренный поток, плотное поле (вдвое больше камней, но медленнее), воронка (центр тянет корабли и камни), глушение (патроны не копятся), мелкий калибр (только мелкие, втрое больше), крупный калибр (только крупные).

### Боссы
| Босс | Волна | Тип | Суть |
|---|---|---|---|
| Сеятель | 5 | Цель | Не атакует, постоянно выбрасывает астероиды, пока жив |
| Рой | 10 | Испытание | 40 мелких камней ходят стеной и перестраиваются; убить нельзя, продержаться 25 с |
| Гигант | 15 | Цель | От каждого попадания откалывается живой кусок |
| Воронка | 20 | Испытание | Неуязвима, тянет корабли и камни; продержаться 30 с; финальная, усиленная |

- Цель: у неё есть прочность, волна идёт, пока босс жив. Прочность масштабируется по числу игроков.
- Испытание: прочности нет, волна длится ровно время испытания. С ростом числа игроков растут плотность Роя и тяга Воронки, время остаётся прежним.

### Усиления
Выпадают из разрушенных астероидов, лежат на поле 10 с, подбираются пролётом.

| Усиление | Эффект | Кому | Режимы |
|---|---|---|---|
| Ремонт | +1 жизнь | Лично; в кооп и командном — в пул | Все |
| Полный боезапас | Патроны до 10 | Лично | Все |
| Щит | 8 с неуязвимости | Лично | Все |
| Заморозка | Астероиды замирают на 3 с | Всем | Кооператив |
| Расчистка | Уничтожает все мелкие астероиды | Всем | Кооператив |
| Перегрузка | ×2 к множителю на 5 с | Лично | Соревнование, командное |
| Глушилка | 3 ближайших соперника 5 с не могут стрелять | Чужим | Соревнование, командное |

Под Глушилкой патроны копятся как обычно, но кнопка Power гаснет с пометкой, что заглушили.

### Гибель, призрак, воскрешение, саботаж
- **Кооператив:** от погибшего остаются 3 светящихся обломка, разлетающихся в разные стороны. Если собрать все три за время призрака, игрок возвращается с 1 жизнью и короткой неуязвимостью. Призрак полупрозрачный: неуязвим, не стреляет, может слегка отталкивать астероиды. Время вышло — игрок выбывает.
- **Командное:** погасший призрак становится саботажником против чужих команд. Попасть по своим он тоже может.
- **Саботаж:** см. раздел 7.

## 6. Контроллер в Space War

Общий контроллер платформы (`ARCADE_HUB_SPEC.md` §10). Space War заказывает в манифесте:

- **Виды управления:** стрелки, гироскоп, джойстик — все три.
- **Главная кнопка — Power.** По краю ободок, который заполняется по часовой стрелке — накопление следующего патрона; заполнился — короткая вспышка. В центре крупно число патронов. На нуле кнопка серая. Данные — в `st.mainButton`.
- Скорость ободка косвенно показывает множитель. Самого множителя на телефоне нет.
- **Под Глушилкой** Power гаснет с пометкой, что заглушили (`st.game.jammed`).
- **Раскладка по руке:**

| Вид | Правша | Левша |
|---|---|---|
| Стрелки | Стрелки слева, Power справа | Зеркально |
| Джойстик | Джойстик слева, Power справа | Зеркально |
| Гироскоп | Только Power справа | Только Power слева |

- **Предупреждение в настройках:** «Корабль в игре — его могут сбить».
- **Строка на паузе:** «Волна N · до конца м:сс».
- **Отключившийся игрок:** корабль `DISCONNECT_INVULN_S` неуязвим и дрейфует.
- **События `fx`:** попадание — вибрация 40 мс и красная вспышка по краям; взрыв — длинная вибрация и белая вспышка; подбор усиления — два коротких импульса.

## 7. Экран саботажника (особая раскладка телефона погибшего)

Эту раскладку добавляет в платформу отдельный этап «Расширение платформы» перед этапом Б10 (`ARCADE_HUB_STAGES.md`). Ниже — что она должна уметь.

### Раскладка
| Зона | Содержимое |
|---|---|
| Левая колонка | 2 квадратные карточки: камень и бомба. Выбранная обведена рамкой в цвет игрока. Сторона ≥ 1/3 высоты экрана, но не меньше 96 точек; зона нажатия шире рисунка на 12 точек; между карточками зазор |
| Правая область | Скруглённая рамка поля **в пропорциях большого экрана** (соотношение сторон приходит от хоста) с пунктирными диагоналями |
| Верх слева | Пауза — только у ведущего (как на обычном контроллере) |
| Верх справа | Шестерёнка настроек |
| Низ | Одна строка подсказки |

- Рамка вписывается в правую область максимально крупно и занимает не меньше 60 % высоты телефона. Если места не хватает, сначала сужается колонка карточек (до 96 точек), потом отступы, и только потом сама рамка.
- Полосы по бокам от рамки — тоже рабочая зона: из них тянут длинную линию.
- Правша/левша зеркалит колонку и поле.
- Контраст от обратного: фон почти чёрный, карточки и рамка светятся. Внутри карточки нет текста, кроме секунд кулдауна.
- Иконки: камень — неровный многоугольник, бомба — круг с фитилём, обе в цвет игрока.
- Ничего не анимируется само по себе, только в ответ на действие.

### Наводка
- Натягивание начинается **в любом месте правой области**: внутри рамки или за ней. Касание левой колонки только выбирает снаряд.
- У точки нажатия белое неподвижное кольцо-якорь. У пальца красное кольцо поменьше, которое движется вместе с пальцем. Линию между ними можно перекладывать сколько угодно, пока палец не отпущен.
- Линия окрашена градиентом от зелёного у якоря к цвету ступени на конце.
- Сила — 4 ступени по длине линии в долях диагонали рамки:

| Ступень | Длина | Цвет конца | Скорость |
|---|---|---|---|
| 1 | < 0,25 | Зелёный | ×0,5 |
| 2 | < 0,5 | Жёлтый | ×1 |
| 3 | < 0,75 | Оранжевый | ×2 |
| 4 | ≥ 0,75 | Красный | ×3 |

- **Точка входа снаряда:** линию продлевают назад от якоря до пересечения с рамкой — снаряд влетает с этой точки края поля и летит по направлению линии. Пример: якорь в центре, палец чуть к правому нижнему углу — медленный снаряд из левого верхнего угла.
- **Отмена:** линия короче 1,5 см (перевести в пиксели через CSS px) или простой тап. Снаряд не уходит, кулдаун не тратится.
- **Прицел на большом экране не показывается.** Снаряд появляется только после отпускания.
- При отпускании: вибрация чуть длиннее обычной (самая длинная на этом экране) и жёлтое кольцо на месте якоря, гаснущее за долю секунды.

### Кулдаун на карточке
- Независимые таймеры: камень 5 с, бомба 8 с, плюс 1 с за каждого погибшего.
- По рамке карточки идёт индикатор, который стирается против часовой стрелки. Сама карточка притушена, в центре крупно секунды.
- Готовность: рамка вспыхивает в цвет игрока, карточка возвращает яркость, **самая короткая** вибрация (щелчок, не похожий на вибрацию выстрела).
- Карточку в кулдауне можно выбрать, но натягивание не начнётся: поле приглушено, подсказка показывает остаток времени.

### Снаряды на поле
- Камень: силуэт как у обычного астероида, но с контуром в цвет отправителя и слабым следом. Прочность 4–5.
- Бомба: заливка в цвет отправителя. Взрывается от касания корабля или астероида, жизней не отнимает, но сильно отбрасывает корабли и астероиды в радиусе.

## 8. Лобби Space War

Общее лобби платформы (`ARCADE_HUB_SPEC.md` §11). Space War добавляет через схему лобби:

- **Форма корпуса** — поле игрока. Скинов нет: только цвет (из профиля) и форма. Формы: треугольник, круг, квадрат, звезда; у каждой своё число вариантов рисунка. Всё открыто сразу, хитбокс у всех одинаковый.
  Варианты: треугольник — Стрела, Дельта, Крыло; круг — Кольцо, Ядро; квадрат — Короб, Ромб; звезда — Звезда, Звезда-4. У симметричных корпусов нос показывает маленький зубец. Боты — Дельта. Телефон выбирает на своём экране, клавиатурные игроки — в карточке на большом экране.
- **Клавиатура:** `keyboardMax = 2`.
- **Боты** разрешены, у всех один статичный корпус. Уровень общий на комнату:

| Уровень | Задержка реакции | Поведение |
|---|---|---|
| Слабый | ~400 мс | Держится с краю, не стреляет |
| Средний | ~200 мс | Уклоняется, отстреливает крупные |
| Сильный | ~80 мс | Сознательно рискует ради множителя, стреляет экономно |

- **Настройки матча** (по умолчанию одинаковы для всех режимов): столкновения кораблей (вкл.); усиления (вкл.); саботаж погибших; стартовая сложность (3 уровня); качество графики (авто или вручную); время призрака (15 с); уровень ботов. Ползунки вспышек, тряски и bloom берутся из настроек хаба. Качество «Авто» в лобби — значит как в настройках хаба.

## 9. Графика и производительность
- Цель: 60 кадров на встроенной графике ноутбука 2015 года, наш бюджет ≤ 8 мс на кадр.
- Один атлас текстур; пулы объектов; фиксированный шаг физики отдельно от отрисовки; пространственная сетка для столкновений.
- Эффекты и уровень качества, с которого они включаются:

| Эффект | С какого качества |
|---|---|
| Параллакс-звёзды в шейдере, тряска, hit-stop, вспышки, аддитивный след | Низкое |
| Частицы до 300, bloom через downsample-blur | Среднее |
| Частицы до 1500, хроматическая аберрация | Высокое |

- Адаптивное качество: замер в первые 3 с, дальше непрерывно; кадр дольше 20 мс в течение 2 с — ступень вниз. Есть ручной переключатель в лобби.
- «Авто» в настройках хаба начинает с высокого качества; ручной выбор (низкое/среднее/высокое) не меняется. Ползунки «Вспышки», «Тряска», «Bloom» и «Уменьшить движение» — из настроек хаба.
- На низком качестве — только короткие осколки камней (до 40 частиц), без искр множителя и bloom.
- Hit-stop — часть симуляции: в записи матча повторяется так же.
- Счётчик FPS — по переключателю «Показывать FPS» в настройках хаба (или `?fps` в адресе).
- Хроматическая аберрация — только импульсом при ударе: постоянная размывала картинку. Подписи кораблей — вне bloom.
- Камера отъезжает на шаг за каждые 2 игрока. Пропорции поля не меняются.

## 11. Итоги и мета Space War
- **Записи матчей:** сохраняются сид и поток ввода с отметками времени, хранятся последние 3. Воспроизведение — пересчёт матча с отрисовкой. Перемотка вперёд — быстрый пересчёт без отрисовки, назад — пересчёт с начала. На шкале метки волн и гибелей. Управление: перемотка, пауза, замедление. Записи, сделанные на другой версии правил, помечаются несовместимыми.
- **Ежедневный сид** и рекорд дня. Результаты привязаны к компьютеру, аккаунтов нет.
- **Карточка игры в меню:** одна строка о последнем матче, например «14 волн · лучший — Мурад, 23 400». По нажатию раскрываются рекорд дня, лучший результат компьютера, таблица рекордов и записи.
- **Экран итогов в три шага:** замедленный повтор последних 5 с матча → корабли в ряд, каждому именная награда из статистики («Живой щит», «Ни царапины», «Самый безрассудный», «Меткий», «Камикадзе»), что-нибудь достаётся каждому → таблица по строке на игрока: корабль, ник, полоска дожитых волн, одна главная цифра; сверху рекорд дня.
- Языки: русский и английский.

## 13. Чего НЕ делать

- Скины как отдельная сущность; открытие форм за достижения.
- Энергетическая связь между кораблями.
- Замедление времени на последней жизни.
- Показ множителя цифрой на телефоне; прицел саботажника на большом экране.
- Усиления «Донор», «Магнит», «Фантом», «Двойной выстрел».
- Бесконечная волна после двадцатой.
- Отскок или телепорт на границах поля.
- Свою комнату, лобби, паузу или настройки телефона внутри папки игры.

## 14. Спорные места — уточнить у заказчика до соответствующего этапа

1. **Цель соревнования.** В таблице режимов сказано «остаться последним», а в правилах — «победитель по очкам» (этап Б7).
2. **Саботаж в кооперативе.** Сказано, что саботаж работает во всех режимах, но в кооперативе погибший — призрак, который собирает обломки, а в настройках саботаж «включён в соревновательных». Становится ли погибший в кооперативе саботажником и по кому он стреляет (этап Б10)?
3. **Таймер простоя множителя.** Решено: `MULT_IDLE_RESET_S = 5` (после проверки в игре; сначала было 3).
4. **Гибель в соревновании.** Для кооператива описан призрак, для командного — призрак, потом саботажник. В соревновании погибший, видимо, сразу становится саботажником — подтвердить (этап Б10).
