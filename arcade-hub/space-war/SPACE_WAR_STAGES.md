# SPACE WAR — этапы разработки игры

Этапы игры **Space War**. Спецификация игры — `SPACE_WAR_SPEC.md` в этой папке, платформы — `../ARCADE_HUB_SPEC.md`.

**Начинать только после этапа А8 платформы** (`../ARCADE_HUB_STAGES.md`): меню, комната, телефоны, лобби и итоги уже должны работать на «Точках».

## Как пользоваться

1. Для каждого этапа открой **новый чат** и вставь общий заголовок игры плюс блок нужного этапа.
2. Этап не закрыт, пока ты сам не проверил пункт «Готово, когда».
3. После каждого этапа убедись, что «Точки» по-прежнему запускаются и доигрываются до итогов — платформа не должна сломаться.

### Общий заголовок игры (вставляется перед каждым этапом)

```
Ты реализуешь игру Space War для платформы Arcade Hub.
Спецификация игры — space-war/SPACE_WAR_SPEC.md, платформы — ARCADE_HUB_SPEC.md в корне.
Прочитай раздел 0 обеих спецификаций и раздел 3 ARCADE_HUB_SPEC.md «Граница платформы и игры».
Весь код игры — только в папке space-war/, импорт только из engine/ и shared/.
Если нужна новая возможность платформы — остановись и предложи этап «Расширение платформы» из ARCADE_HUB_STAGES.md.
Делай только этап, описанный ниже. Если в спецификации чего-то не хватает или она противоречит сама себе — остановись и спроси.
В конце: проект собирается без ошибок, запускается одной командой, «Точки» работают. Напиши отчёт: что сделано, как проверить, какие решения ты принял сам.
```

## Б0 — Модуль Space War

```
Этап Б0. Каркас игры.
Сделай:
- Папка space-war/ в корне репозитория — из копии шаблона dots/. Добавь игру в реестр shared/games.ts.
- Манифест Space War (ARCADE_HUB_SPEC §16; манифест — SPACE_WAR_SPEC §12): название, слоган, accent #3DE0FF, 1–10 игроков, keyboardMax 2, три режима, «Как играть», controllerLayout (джойстик/стрелки/гироскоп + Power).
- config.ts со ВСЕМИ константами SPACE_WAR_SPEC §4 (TUNE — разумные заглушки с комментарием).
- features.ts — флаги фич (shooting, powerups, sabotage, collisions).
Готово, когда: Space War появляется в меню, из окна игры открывается пустое поле со счётчиком FPS и возвращается в хаб.
```

## Б1 — Корабль

```
Этап Б1. Корабль (SPACE_WAR_SPEC §5 «Поле и корабль»).
Сделай: корабль с массой, тягой, сопротивлением и пределом скорости; управление через общий ввод платформы (клавиатура и телефон); жёсткие границы без отскока; хитбокс-окружность; простой неоновый контур.
Готово, когда: кораблём приятно рулить и с клавиатуры, и с телефона — он разгоняется, плавно тормозит, не залипает у стен.
```

## Б2 — Астероиды

```
Этап Б2. Астероиды (SPACE_WAR_SPEC §5 «Астероиды», §9).
Сделай: спавн с краёв через rng, дрейф, уход за границу; три размера и раскол; процедурные формы в текстурах; сетка столкновений; минус жизнь и короткая неуязвимость, 5 жизней; осколки не ранят; конец игры и итоги через платформу; пулы.
Готово, когда: есть одиночная игра с проигрышем; при одинаковом сиде астероиды появляются одинаково.
```

## Б3 — Стрельба и экономика

```
Этап Б3. Стрельба, патроны, множитель, очки (SPACE_WAR_SPEC §5).
Сделай:
- Power: выстрел с автонаведением на ближайший астероид.
- Прочность астероидов по ASTEROID_HP, три визуальных состояния.
- Патроны: максимум 10, t = AMMO_BASE_S / (1 + 0.4·(m−1)); число и ободок отправляются на телефон в st.
- Множитель: ступени MULT_STEPS, каждый камень один раз, пауза 0,5 с, обнуление при ударе и простое (MULT_IDLE_RESET_S — см. SPACE_WAR_SPEC §14 п. 3).
- Очки по таблице SPACE_WAR_SPEC §4.
- Показ множителя на большом экране: цифра у ника с ×2, свечение и след по ступеням.
Не делай: bloom и дорогие эффекты (Б4), Перегрузку (Б11).
Готово, когда: ядро играется целиком и не ломается на плотном поле — ×5 не набирается за секунды, патроны не бесконечны.
```

> **Точка проверки игры 1.** Дай поиграть человеку со стороны. Если игра не затягивает на пару минут, проблема в ядре — чини до Б4.

## Б4 — Визуал и производительность

```
Этап Б4. Визуал (SPACE_WAR_SPEC §9, §5 «Показ множителя»).
Сделай: параллакс-звёзды, неоновые контуры, аддитивный след; частицы с лимитами, тряска, hit-stop, вспышки; bloom, хроматическая аберрация на высоком; три уровня качества с адаптивным понижением; общий лимит частиц для эффектов множителя; ползунки вспышек, тряски, bloom берутся из настроек хаба; единый атлас.
Готово, когда: выглядит дорого и держит 60 кадров на старом ноутбуке со встроенной графикой (throttling CPU в DevTools).
```

## Б5 — Лобби Space War

```
Этап Б5. Поля Space War в общем лобби (SPACE_WAR_SPEC §8) через схему общего лобби (ARCADE_HUB_SPEC §11).
Сделай: форма корпуса (треугольник, круг, квадрат, звезда и варианты рисунка), два клавиатурных слота со схемой клавиш, настройки матча из SPACE_WAR_SPEC §8. Цвета игроков берутся из профиля хаба.
Готово, когда: двое с клавиатуры и телефоны выбирают корпус и играют вместе.
```

## Б6 — Десять игроков и боты

```
Этап Б6. Масштаб (SPACE_WAR_SPEC §5, §8, §9).
Сделай: до 10 кораблей с никами; камера отъезжает на шаг за каждые 2 игрока; поведение ботов трёх уровней (задержка 400/200/80 мс); поток камней × (1 + 0.5·(N−1)).
Готово, когда: десять ботов не превращают экран в кашу и не расчищают поле за секунду, FPS держится.
```

## Б7 — Режимы

```
Этап Б7. Режимы (SPACE_WAR_SPEC §5 «Режимы»).
Сделай: кооператив с общим пулом, соревнование (победитель — SPACE_WAR_SPEC §14 п. 1), командное по цвету; столкновения и таран (множитель теряют оба, в кооперативе не работает).
Готово, когда: все три режима проходятся от лобби до итогов.
```

> **Точка проверки игры 2.** Первая игра на 4–5 живых людях. Баланс и понятность — чинить сейчас, до Б8–Б11.

## Б8 — Волны

```
Этап Б8. Волны (SPACE_WAR_SPEC §5 «Волны»).
Сделай: 20 волн, длительность min(30 + 3·(n−1), 60) с, пауза 5 с с подписью; рост плотности и скорости; осложнения через rng; очки за волну; финиш после 20-й; места под боссов.
Готово, когда: есть ритм, рост напряжения и финиш.
```

## Б9 — Боссы

```
Этап Б9. Боссы (SPACE_WAR_SPEC §5 «Боссы»).
Сделай: Сеятель (5), Рой (10, 25 с), Гигант (15), Воронка (20, 30 с, финальная); прочность целей × (1 + 0.7·(N−1)); испытания масштабируются плотностью и тягой.
Готово, когда: финал ощущается как финал, а на 10 игроках Гигант не падает за две секунды.
```

## Б10 — Саботаж и воскрешение

```
Этап Б10. Гибель, призрак, воскрешение, саботаж (SPACE_WAR_SPEC §5, §7).
Перед началом уточни у заказчика SPACE_WAR_SPEC §14 пп. 2 и 4.
Экран саботажника на телефоне — новая раскладка контроллера. Если платформа её ещё не умеет, сначала сделай отдельный этап «Расширение платформы: раскладка саботажника» в controller/ и shared/ по ARCADE_HUB_STAGES.md, проверь её на «Точках», и только потом подключай в Space War.
Сделай: обломки и призрак в кооперативе; саботажник в командном; экран саботажника строго по SPACE_WAR_SPEC §7; снаряды камень и бомба в цвет отправителя; кулдаун 5/8 с + 1 с за каждого погибшего.
Готово, когда: погибшие не скучают и не уходят от экрана, а в соперника можно попасть, почти не глядя на телефон.
```

## Б11 — Усиления

```
Этап Б11. Усиления (SPACE_WAR_SPEC §5 «Перегрузка», «Усиления»).
Сделай: выпадение 1/20, 10 с на поле; семь усилений, по 5 на режим; Перегрузка отдельным слоем (значок «×2», бордовый, не сгорает при ударе, повторный подбор обновляет таймер); Глушилка на 3 ближайших; флаг в настройках матча.
Готово, когда: два матча подряд не похожи друг на друга.
```
